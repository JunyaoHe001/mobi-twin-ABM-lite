Public-data preparation

The private preparation process aligns source tables internally through a temporary source key. That key is never written to a public output.

Transformation sequence

  1. Read only model-relevant variables in a private environment.
  2. Restrict destination probabilities to the 38 Central Macedonia regions used by the demonstration.
  3. Cluster exit curves into 10 monotone public profiles.
  4. Cluster destination distributions into 24 smoothed public profiles.
  5. Cluster source records into synthetic archetypes using demographic, socioeconomic, preference, and profile-membership features.
  6. Merge small clusters into viable aggregate groups.
  7. Convert groups into rounded, perturbed distributions and summary statistics.
  8. Convert regional boundaries to simplified WGS84 GeoJSON.
  9. Write only public JSON outputs and perform identifier and path scans.

Public files

  • archetypes.json: aggregate synthetic-population components;
  • exit_profiles.json: clustered exit profiles;
  • destination_profiles.json: clustered destination profiles;
  • regions.geojson: simplified regional boundaries;
  • model_config.json: public scenarios and rounded demonstration parameters;
  • generation_report.json: generation and disclosure audit.

Raw inputs, original identifiers, temporary mappings, and the private model are not copied into the public repository.
